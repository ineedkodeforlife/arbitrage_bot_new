# Сканер вилок BC Game + Polymarket

Ищет ситуации, когда ставка в BC Game и покупка противоположного исхода на Polymarket
вместе дают прибыль при любом результате матча. Только поиск и расчёт — ставки
сканер не делает.

## Запуск

Нужен только Python 3.10+, сторонних библиотек нет.

```bash
python scan.py
```

Лайв (идущие матчи), непрерывно:

```bash
python scan.py --live --loop 0 --min-profit 1
```

Со звуком и страницей в браузере:

```bash
python scan.py --live --loop 0 --min-profit 1 --sound --web
```

После запуска откройте `http://localhost:8765` и один раз нажмите «Включить
уведомления и звук» — браузер спросит разрешение. Дальше при каждой новой вилке
приходит системное уведомление и звуковой сигнал, даже если вкладка свёрнута
(закрывать её нельзя). Страница получает данные от сканера напрямую, без опроса
и без внешних сервисов, и доступна только с этого компьютера. Повторный сигнал по
той же вилке — не раньше чем через минуту после её исчезновения.

Полезные параметры:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `--hours 24` | брать матчи, начинающиеся в ближайшие N часов | 48 |
| `--min-profit 1` | показывать вилки от N % | 0 |
| `--bank 500` | на какую сумму считать распределение ставок | 100 |
| `--near 10` | дополнительно показать N связок, ближайших к вилке | 0 |
| `--live` | сканировать идущие матчи вместо прематча | прематч |
| `--loop 60` | повторять проход каждые N секунд; `--loop 0` — без пауз | один проход |
| `--pm-refresh 30` | как часто в цикле обновлять список игр Polymarket, с | 30 лайв / 120 прематч |
| `--sound` | звуковой сигнал на компьютере при новой вилке | нет |
| `--web [порт]` | страница с вилками и уведомлениями в браузере | нет (порт 8765) |
| `--passes 10` | остановиться после N проходов | без ограничения |
| `--csv arbs.csv` | дописывать найденные вилки в файл | нет |
| `--verbose` | подробности по загрузке и несопоставленным событиям | нет |

## Как это работает

1. **BC Game** (`arb/bcgame.py`). Спортбук работает на движке Betby, прематч-линия
   отдаётся обычными GET-запросами с `*.sptpub.com` без авторизации. В снимке только
   основные рынки каждого матча.
2. **Polymarket** (`arb/polymarket.py`). Список игр — публичный Gamma API,
   стаканы — публичный CLOB API. Ключи не нужны.
3. **Сопоставление** (`arb/match.py`). Событие считается одним и тем же, если совпал
   вид спорта, обе команды и время начала (допуск 3 часа, для тенниса и единоборств 12).
4. **Расчёт** (`arb/calc.py`). Цена Polymarket берётся из стакана с учётом комиссии
   тейкера `rate × p × (1 − p)` на акцию (для спорта rate = 0.05). Объём считается
   по глубине стакана: пока следующий уровень цены ещё даёт прибыль.

## Скорость

В цикле проход занимает около 0,3 с: ~0,23 с — запрос изменений линии BC Game,
~0,08 с — стаканы Polymarket. За счёт чего:

- **BC Game:** полный снимок качается один раз, дальше — только изменения с прошлого
  запроса (так же обновляется сама страница). Сервер выпускает изменения раз в ~2 с,
  поэтому опрашивать чаще смысла нет.
- **Polymarket:** тяжёлый список игр обновляется в фоновом потоке и не тормозит
  проходы; на каждом проходе запрашиваются только стаканы, пачками и параллельно,
  по постоянным соединениям (без повторного TLS-рукопожатия).
- Запросы к BC Game идут через системный `curl`: при подключении из Python поток
  с их CDN может замирать после 16 КБ. `curl` есть в Windows 10/11 из коробки.

В лайве на Polymarket у спортивных рынков есть задержка исполнения рыночных ордеров
(несколько секунд), а BC Game принимает лайв-ставку с задержкой и может её отклонить —
цена, которую показал сканер, не гарантирована.

Какие рынки сравниваются:

| Вид спорта | Рынки |
|---|---|
| Футбол | исход 1X2 и двойной шанс против «Да»/«Нет» на Polymarket, тотал, фора (основное время) |
| Баскетбол, ам. футбол, бейсбол | победитель, тотал, фора (с овертаймом) |
| Хоккей | победитель с учётом овертайма и буллитов |
| Теннис, единоборства, киберспорт и др. | победитель матча |

Тоталы и форы сравниваются только на линиях вида x.5, чтобы не было возвратов.

## Что проверять руками перед ставкой

- **Правила расчёта.** При отмене, переносе, отказе игрока, ничьей в единоборствах
  BC Game обычно делает возврат, а Polymarket может закрыть рынок 50/50 или по
  своим правилам. Правила конкретного рынка написаны на его странице.
- **Это тот же матч.** Женские и молодёжные команды иногда называются так же, как
  основные. Ссылки на обе страницы есть в выводе.
- **Коэффициент ещё действует.** Линия BC Game в снимке может отставать на несколько
  секунд, а BC Game может урезать максимум ставки.
- **Доходность выше 15 %** сканер помечает `[!]` — почти всегда это ошибка
  сопоставления или устаревшая цена.

## Если перестало работать

Хост и идентификатор бренда BC Game заданы константами `API` и `BRAND` в
`arb/bcgame.py`. Актуальные значения видны в сетевых запросах страницы
`bc.game/sports` (запросы к `sptpub.com`).
