# Сканер вилок BC Game + Polymarket

Ищет ситуации, когда ставка в BC Game и покупка противоположного исхода на Polymarket
вместе дают прибыль при любом результате матча. Только поиск и расчёт — ставки
сканер не делает.

## Запуск

Нужен только Python 3.10+, сторонних библиотек нет.

Один снимок (прематч и лайв вместе):

```bash
python scan.py
```

Непрерывно, со звуком и страницей в браузере — основной режим:

```bash
python scan.py --watch --min-profit 1 --sound --web
```

В режиме `--watch` сканер не опрашивает площадки по таймеру, а слушает их потоки:
вилка печатается в тот момент, когда пришло изменение коэффициента или стакана.
Когда вилка закрывается, печатается, сколько секунд она держалась.

После запуска с `--web` откройте `http://localhost:8765` и один раз нажмите «Включить
уведомления и звук» — браузер спросит разрешение. Дальше при каждой новой вилке
приходит системное уведомление и звуковой сигнал, даже если вкладка свёрнута
(закрывать её нельзя). Страница доступна только с этого компьютера. Повторный сигнал
по той же вилке — не раньше чем через минуту после её исчезновения.

Параметры:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `--watch` | работать непрерывно | один снимок |
| `--mode live` | `all` — прематч и лайв, `prematch`, `live` | all |
| `--hours 24` | брать матчи, начинающиеся в ближайшие N часов | 48 |
| `--min-profit 1` | показывать вилки от N % | 0 |
| `--min-volume 20` | не показывать вилки, в которые помещается меньше N долларов | 0 |
| `--hold 5` | в `--watch` сообщать о вилке, когда она продержалась N секунд (0 — сразу) | 3 |
| `--max-profit 15` | не показывать вилки с доходностью выше N % | показывать все |
| `--bank 500` | на какую сумму считать распределение ставок | 100 |
| `--near 10` | дополнительно показать N связок, ближайших к вилке | 0 |
| `--sound` | звуковой сигнал на компьютере при новой вилке | нет |
| `--web [порт]` | страница с вилками и уведомлениями в браузере | нет (порт 8765) |
| `--csv arbs.csv` | журнал вилок: когда появилась, сколько держалась, максимум | нет |
| `--status 15` | как часто печатать строку состояния, с | 15 |
| `--pm-refresh 60` | как часто обновлять список игр Polymarket, с | 60 |
| `--duration 600` | остановиться через N секунд | без ограничения |
| `--tg-token`, `--tg-chat` | уведомления в Telegram (см. ниже) | нет |
| `--proxy host:port` | HTTP-прокси для линии BC Game (`none` — без прокси) | из системы |
| `--verbose` | подробности по загрузке и несопоставленным событиям | нет |

### Страница в браузере

- **Таймер** на каждой вилке показывает, сколько она уже держится. Вилки моложе
  `--hold` секунд показаны приглушённо, без звука и уведомлений: секундные всплески
  в лайве (после гола, раунда) руками всё равно не поймать. В журнал `--csv` попадают все.
- **Порядок:** сначала прематч (живёт минутами), потом лайв; внутри — по доходности.
- **Калькулятор:** введите сумму ставки в BC Game (лучше круглую) — страница покажет,
  сколько акций купить на Polymarket, сколько это стоит по текущему стакану и какая
  выйдет прибыль. Суммы копируются кнопкой. Ставьте сначала в BC Game: он может
  отклонить или урезать ставку, и тогда вы ещё ничего не потеряли.
- **Скрыть** связку, матч или вид спорта — вилки по ним перестают показываться
  и сигналить везде (страница, консоль, Telegram). Список скрытого — вверху страницы,
  там же кнопка «Показать всё». Он хранится в файле `hidden.json`; скрытые матчи
  забываются через три дня.

### Уведомления в Telegram

1. Напишите [@BotFather](https://t.me/BotFather), создайте бота командой `/newbot`,
   получите токен.
2. Напишите своему боту любое сообщение и узнайте свой chat_id (его показывает,
   например, @userinfobot).
3. Задайте их переменными окружения и запустите сканер:

```bash
set ARB_TG_TOKEN=123456:ABC...
set ARB_TG_CHAT=123456789
python scan.py --watch --min-profit 1 --web
```

При запуске бот пришлёт пробное сообщение; если оно не дошло, сканер напишет причину
и продолжит работу без Telegram. Сообщение о вилке содержит ставки на `--bank` и обе
ссылки. Токен лучше не передавать ключом `--tg-token`: он останется в истории команд.

Старые ключи `--live` и `--loop N` по-прежнему работают (`--loop` включает `--watch`).

Проверки без сети: `python -m unittest discover tests`.

## Какие рынки сравниваются

| Вид спорта | Рынки |
|---|---|
| Футбол (основное время) | исход 1X2 и двойной шанс против «Да»/«Нет» на Polymarket, тотал, фора, обе забьют |
| Баскетбол, ам. футбол, бейсбол | победитель, тотал, фора (с овертаймом) |
| **Киберспорт** — CS2, Dota 2, LoL, Valorant, Rainbow Six, Honor of Kings и др. | победитель матча, победитель каждой карты, тотал карт, фора по картам |
| Теннис | победитель, победитель сета, тотал геймов, фора по геймам, фора по сетам |
| Хоккей | победитель с учётом овертайма и буллитов |
| Единоборства, волейбол, дартс, настольный теннис, крикет, австралийский футбол, бадминтон, снукер | победитель матча |

Тоталы и форы сравниваются только на линиях вида x.5, чтобы не было возвратов.
Киберспортивная дисциплина определяется по названию игры, поэтому новая дисциплина
подхватывается сама, если она есть на обеих площадках (таблица названий —
`arb/sports.py`).

Не сравниваются: гандбол и регби (в BC Game только исход основного времени, на
Polymarket — победитель с дополнительным временем), тоталы и форы хоккея (то же
расхождение), симуляторы вроде eSoccer.

## Как это работает

1. **BC Game** (`arb/bcgame.py`). Спортбук работает на движке Betby, линия отдаётся
   GET-запросами с `*.sptpub.com` без авторизации. Сканер один раз качает полный
   снимок прематча и лайва, а дальше читает поток изменений: сервер выпускает новую
   версию раз в секунду и держит запрос открытым, пока она не готова (long-poll).
2. **Polymarket** (`arb/polymarket.py`, `arb/books.py`). Список игр — публичный Gamma
   API, обновляется в фоне раз в минуту. Стаканы — поток WebSocket: биржа сама
   присылает каждое изменение. Ключи не нужны.
3. **Сопоставление** (`arb/match.py`). Событие считается одним и тем же, если совпал
   вид спорта, обе команды и время начала (допуск 3 часа; теннис и единоборства — 12,
   киберспорт — 6, настольный теннис — 45 минут). Если уверенно совпала одна команда,
   время совпало точно, а у второй команды есть общее слово («UConn Huskies» и
   «Connecticut Huskies»), пара принимается с пометкой «проверьте вручную».
4. **Расчёт** (`arb/calc.py`, `arb/engine.py`). При каждом изменении пересчитываются
   только связки, в которых участвует изменившийся коэффициент или стакан. Цена
   Polymarket берётся из стакана с учётом комиссии тейкера `rate × p × (1 − p)` на
   акцию (для спорта rate = 0.05). Объём считается по глубине стакана: пока следующий
   уровень цены ещё даёт прибыль.

## Скорость

| Что | Было | Стало |
|---|---|---|
| Запрос к BC Game | ~350 мс (запуск `curl` на каждый запрос) | 35–60 мс по постоянному соединению |
| Изменение коэффициента BC Game | видно на следующем проходе | через 0,2–0,6 с после появления на сервере |
| Изменение стакана Polymarket | опрос раз в проход, 80–400 мс | приходит само, десятки миллисекунд |
| Пересчёт после изменения | весь проход, ~0,3 с | доли миллисекунды |

Строка состояния показывает отставание каждой площадки. Оно считается по часам
компьютера, поэтому при неточных часах может быть сдвинуто (даже чуть меньше нуля).

**Про прокси.** Напрямую из некоторых сетей ответы линии BC Game обрываются после
первых 16 КБ. Сканер сам находит HTTP-прокси (переменная `HTTPS_PROXY` или системные
настройки Windows) и держит через него постоянное соединение; если прокси нет —
пробует напрямую; если и так не выходит — запускает `curl` на каждый запрос, как
раньше (медленнее на ~300 мс). Какой способ выбран, видно в строке «Готово за …».

В лайве на Polymarket у спортивных рынков есть задержка исполнения рыночных ордеров
(несколько секунд), а BC Game принимает лайв-ставку с задержкой и может её отклонить —
цена, которую показал сканер, не гарантирована. Журнал `--csv` показывает, сколько
секунд живут вилки: в лайве большинство держится 1–5 секунд.

## Что проверять руками перед ставкой

- **Правила расчёта.** При отмене, переносе, отказе игрока, ничьей в единоборствах
  BC Game обычно делает возврат, а Polymarket может закрыть рынок 50/50 или по
  своим правилам. Правила конкретного рынка написаны на его странице.
- **Это тот же матч.** Женские и молодёжные команды иногда называются так же, как
  основные. Ссылки на обе страницы есть в выводе. Пары с пометкой «матч сопоставлен
  по одной команде» проверяйте обязательно.
- **Киберспорт и теннис.** Если карта или сет не были сыграны, BC Game делает
  возврат, а Polymarket закрывает рынок 50/50. То же при отказе игрока в теннисе
  на рынках тоталов и фор.
- **Коэффициент ещё действует.** BC Game может урезать максимум ставки или
  пересчитать коэффициент при приёме.
- **Доходность выше 15 %** сканер помечает `[!]` — почти всегда это ошибка
  сопоставления или устаревшая цена.

## Если перестало работать

Хост и идентификатор бренда BC Game заданы константами `API` и `BRAND` в
`arb/bcgame.py`. Актуальные значения видны в сетевых запросах страницы
`bc.game/sports` (запросы к `sptpub.com`).
